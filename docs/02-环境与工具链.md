## 二、PC 侧交叉编译（zig）

```powershell
# zig 0.13.0 自带 clang + glibc sysroot
$ZIG = 'C:\Users\qq410\WorkBuddy\2026-11-02-10-05-59\zig-windows-x86_64-0.13.0\zig.exe'
$T   = 'aarch64-linux-gnu.2.33'          # 必须 ≤ 设备 glibc

& $ZIG cc -target $T -O2 -std=gnu89 -w `
    -I<src> -I<lua-5.2.4/src> -I<minizip> -I<zlib> `
    -I<SDL2-2.30.8/include> -I<Bass/include> -I<tinypot/include> `
    -c -o build\obj\game\sdlfun.o src\sdlfun.c

# 链接：设备只有 .so.0，没有开发软链，写全名
& $ZIG cc -target $T -O2 -o build\jysdllua *.o `
    -L<sysroot>/usr/trimui/lib -L<sysroot>/usr/lib `
    -l:libSDL2-2.0.so.0.3000.8 -l:libSDL2_image-2.0.so.0.2.3 `
    -l:libSDL2_ttf-2.0.so.0.14.1 -l:libbass.so -l:libbassmidi.so `
    -Wl,-rpath,/usr/trimui/lib:/usr/lib:'$ORIGIN' -lc -lpthread -lm -ldl
```

要点：

1. **glibc tag 不能超过 2.33**，否则设备报 `version GLIBC_2.xx not found`；
2. `-rpath` 里带 `$ORIGIN`，让引擎优先在自己目录找随附库；
3. `build.ps1` 必须是 **UTF-8 with BOM**，否则中文路径下 PowerShell 解析失败；
4. 编译只编「引擎 + Lua + zlib/minizip」，不重编 SDL2（设备库版本 2.30.x 与我们头文件对齐）。

完整脚本见 `patches/build.ps1`。

## 三、部署与回滚（不用 reboot）

```powershell
$k='C:\Users\qq410\.ssh\id_ed25519_zcode'; $h='root@192.168.50.98'
$S=@('-o','BatchMode=yes','-o','StrictHostKeyChecking=accept-new','-o','ConnectTimeout=15','-i',$k)
& scp @S .\build\jysdllua "${h}:/mnt/SDCARD/Ports/jysdlbh/jysdllua.new"
& ssh @S $h 'cd /mnt/SDCARD/Ports/jysdlbh; md5sum jysdllua.new | cut -c1-32; mv jysdllua jysdllua.prev; mv jysdllua.new jysdllua; chmod 777 jysdllua'
```

- 先推 `.new` 再 `mv -f` 覆盖：避免"推到一半断电"留下半个二进制；
- 保留 `jysdllua.prev` 就是回滚点；
- **`reboot` 指令在本机被安全策略硬性拦截，不要尝试**；需要重启请让用户手动操作；
- 远端单条命令超过 15 s 会被切到后台，取结果要阻塞等待（`TaskOutput(block=true)`）。

## 四、启动与停止

```sh
cd /mnt/SDCARD/Ports/jysdlbh
setsid sh launch.sh > /tmp/lNN.log 2>&1 &
sleep 14; pidof jysdllua      # 约 14~17 s 后出现
```

- `launch.sh` 会 `kill -STOP MainUI` 并在退出时 `kill -CONT` 恢复（标志文件 `/tmp/jy4_ui_paused`，防重复挂起）；
- 引擎**不响应 SIGTERM**（`kill -TERM` 打不死），正常退出走游戏内「离开游戏」；外部清理用 `kill -9`，`trap` 仍会恢复 MainUI；
- **千万不要 `pkill -9 MainUI`**：`runtrimui.sh` 的循环会退出，屏幕被 `trimuitools` 的设置页占据。恢复办法：

```sh
cd /usr/trimui/bin
export LD_LIBRARY_PATH=/usr/trimui/lib
setsid ./MainUI > /tmp/mainui.log 2>&1 &
```

## 五、自写调试工具（都在 `tools/`）

| 工具 | 用途 | 说明 |
|---|---|---|
| `raw2png.py` | `/dev/fb0` 原始帧转 PNG | 用法：`python raw2png.py x.raw 1024 768 4096 bgra out.png`，**必须位置参数** |
| `jyinject.c` | 用 `/dev/uinput` 造虚拟键盘注入按键 | `./jyinject <起始延迟秒> "key,w1,key,..."`，键名 `up down left right esc enter space tab shift alt a b e t`，`wN`=等 N 秒 |
| `jyopen.c` | `open/fopen` 日志 shim（`LD_PRELOAD`） | 只在含 `Help` 的路径打日志；在本机被 fortify 内联绕过，**未产出日志**（见 10 章） |
| `head_fix.py` | 立绘按最长边封顶 | 纯 Python 自写 PNG 编解码 + 盒式平均，无需 PIL |
| `png_hole.py` | 量遮罩镂空包围盒 | 从中心做透明连通填充，取包围盒 |
| `make_bars*.py` | 生成上下机框遮罩 | 三张候选见 `release/overlays/` |
| `elf_needed.py` | 解析 ELF `DT_NEEDED` | 判断"能不能换库"的第一步 |

**抓帧命令（唯一可信的画面取证方式）**

```sh
dd if=/dev/fb0 of=/tmp/x.raw bs=4096 count=768     # 1024×768、stride 4096 → 768 行
# 第 2 页（y=768..1535）是空白，抓第 1 页即可
```

## 六、按键注入的节奏（踩过的坑）

- `jyinject` 走 `/dev/uinput`，设备名 `jy-test-kbd`；
- **注入太快会丢键**：曾因连发 `down` 触发「请选择内力性质」弹窗；
- 稳定节奏：**每个键后加 `w1`**（等 1 秒），批次之间 `w2`；
- 已验证导航链（从标题页开始）：
  - `down,w1,enter,w2` → 读取进度；`enter,w2` → 载入 1 号档
  - 游戏内 `esc,w2` → 主菜单 6 项（医疗/解毒/物品/状态/离队/系统）
  - `down×5,w1,enter,w2` → 系统子菜单 8 项（读取/保存/关音乐/关音效/**系统攻略**/功能加强/设置/离开）
  - `down×4,w1,enter,w3` → 打开系统攻略

## 七、SSH 经验（BusyBox 环境）

- 多行脚本直接管道会**静默丢段**：改用 base64 单行下发，或写成 `.sh` 推上去再执行；
- 输出可能被截断，关键结果（md5、`pidof`、`ls -l`）单独打印、加分隔符；
- 设备无 `ldd`：判断动态链接问题用「试跑 + `error.txt`」或 `readelf -d`（若把 readelf 推到设备）；
- 设备重启后 dropbear 自启不可靠，先确认 22 端口通再推文件。
