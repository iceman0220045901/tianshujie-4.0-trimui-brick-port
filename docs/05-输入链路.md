# 05 · 输入链路：手柄 → gptokeyb → 虚拟键盘 → SDL

---

## 一、现象

画面正常，但十字键、ABXY、Start/Select 按下去毫无反应，菜单卡在「重新开始」。

## 二、根因

引擎的 `JY_GetKey()` 只处理 **SDL 键盘事件**（`SDL_KEYDOWN`）。掌机的按键不是键盘，而是一个手柄 `TRIMUI Player1`（`/dev/input/event3`、`js0`）——SDL 只把它当 joystick，不会翻译成键盘键值。所以引擎在键盘总线上一个事件都收不到。

旧版天书劫（`Ports/Jinyong`）能用，是因为它挂了一层 `gptokeyb`：读手柄 → 通过 `/dev/uinput` 造一个虚拟键盘 → 把按键翻译成键盘键值再喂给引擎。

---

## 三、做法（不改一行引擎源码）

1. 从旧版目录取 `gptokeyb` 与 `jysdllua.gptk`；
2. `launch.sh` 里两段：

```sh
# gptokeyb 自己也依赖 SDL2，必须在它启动前把库路径导好，否则静默失效
export LD_LIBRARY_PATH="$PWD/lib:/usr/trimui/lib:/usr/lib:"

# 先行启动，让引擎初始化 SDL 时就能枚举到这块虚拟键盘
./gptokeyb -k "jysdllua" -c "./jysdllua.gptk" > /tmp/jysdlbh_gptk.log 2>&1 &
GPTOKEYB_PID=$!
sleep 1
```

3. `cleanup()` 里 `kill -9 $GPTOKEYB_PID`；快速退出重试时重新拉起。

### 键位表（`jysdllua.gptk`）

```
back = esc          start = enter
up = up             down = down           left = left         right = right
a = esc             b = space             x = leftshift       y = leftalt
l1 = e              l2 = tab              l3 = esc
r1 = t              r2 = backspace        r3 = \"
left_analog_up/down/left/right  = up/down/left/right
right_analog_* = \"
```

两处引擎特例：`JY_GetKey()` 把 `SDLK_SPACE` 改写为 `SDLK_RETURN`（所以 `b = space` 实际就是确认键）；`a` 与 `back` 都映射 `esc`。

改键位只改 `.gptk` 再重启 port，**不用重编引擎**。

---

## 四、怎么证明「按键真的进来了」（三层证据）

只看到「进程起来了」不算通。必须逐层验证：

| 层 | 证据 | 本例结果 |
|---|---|---|
| 进程并存 | `pidof gptokeyb`、`pidof jysdllua` | `21836` / `21844` |
| gptokeyb 读手柄 | `/proc/<gptk pid>/fd` | `4 -> /dev/uinput`、`5 -> /dev/input/event3`（TRIMUI Player1） |
| 引擎收键盘 | `/proc/<game pid>/fd` | 打开 `event0`(sunxi-keyboard)、`event1`、`event2`、`event4` |
| 虚拟键盘存在 | `/sys/class/input/input4/name` | `Fake Keyboard`，对应 `event4` |
| 按键进了引擎 | 自建 `jyinject` 注入 + 引擎 `keylog.txt` | 注入两次 `KEY_DOWN`，收到两帧 `sym=1073741905`（`SDLK_DOWN`） |
| 菜单真的动了 | 整帧对比 | 高亮「重新开始」→「载入进度」→「系统设置」 |

结论：**手柄 → gptokeyb → Fake Keyboard → SDL → 引擎 → 菜单** 全链路打通。

### 自查某个键到底发没发出去

```sh
JY_KEYLOG=1 ./jysdllua        # 或在 launch.sh 里临时 export
# 每按一次键，目录下 keylog.txt 多一行 sym=<SDL 键值>
```

常用键值：`SDLK_DOWN=1073741905`、`SDLK_UP=1073741906`、`SDLK_ESC=27`、`SDLK_RETURN=13`。

## 五、`jyinject`：远程无头调试的杀手锏

真机在手边时用手按；机器不在手边、或需要精确复现「按了几次、间隔多久」时，用注入。

```sh
./jyinject 1 "esc,w2,down,w1,down,w1,down,w1,enter,w3"
#             ↑起始延迟 ↑每键后等 1 秒（太快会丢键）
```

实现：打开 `/dev/uinput`，注册一个名为 `jy-test-kbd` 的虚拟键盘，按序列发 `KEY_*` 事件。

**踩过的坑**：早期连发 `down` 丢了按键，游戏走进「请选择内力性质」分支。**每个键后必须 `w1`**。

## 六、退出与恢复

- 引擎不响应 `SIGTERM`，正常退出走游戏内「离开游戏」；
- 外部 `kill -9` 后 `launch.sh` 的 `trap cleanup` 仍会恢复 MainUI；
- 误杀 MainUI 的恢复办法见 [02 · 启动与停止](02-环境与工具链.md)。
