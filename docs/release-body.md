## v1.0.0 · 天书劫 4.0 原味强化版 · 吹米（TrimUI Brick）移植首个发布

把 Windows 上跑的《金庸群侠传 mod 天书劫 原味强化版 4.0》搬到了 TrimUI Brick（Allwinner A133 / 1024×768 / glibc 2.33 / FAT32 卡），并把这套流程写成可复用的移植文档。

### 这一版做到了

- **画面**：给 SDL2 引擎新增 `/dev/fb0` 直写后端（`JY_FBDEV=1`，默认仍走原 Mali/EGL，零回归）；内部渲染面保持 1280×720（4.0 的排版尺寸），0.8 等比缩到 1024×576 满宽不变形；缩小时用盒式平均，中文笔画不再断；上下 96 px 用机框遮罩盖住。
- **输入**：gptokeyb → `/dev/uinput` 虚拟键盘 → SDL 键盘事件，手柄全键可用；自建 `jyinject` + `JY_KEYLOG` 把「按键是否真的进引擎」验证到逻辑层。
- **音频**：修 BASS_MIDI 解码入口（`code=41` → `active=1`）、扩展名大小写、`CONFIG.MP3=0` 音色库、音量 50/40、**音乐/音效默认打开**；战斗内音效已确认可听。
- **立绘**：补回被引擎丢弃的 `zoom` 参数，再改为**固定框 146**（大图缩、小图放大），彻底解决「mod 立绘正常、原版人物太小」。
- **内置攻略**：定位「系统攻略点了直接回游戏」的根因——引擎要 `data/Help/`（大写 H），卡上是 `data/help`，且这块 FAT32 查找区分大小写；菜单是资源存在性驱动，缺文件就空菜单静默返回。修复后 16 本齐全，**已完成剧情变绿带「（完成）」**。

### 已知问题（如实记录）

- 上下遮罩与画面顶部之间约 3 px 细缝（权衡后保留，不吃画面）。
- 过场 MPEG 在直写模式下跳过（依赖真实窗口）。
- 直写单缓冲无 vsync，快速横移可能撕裂。
- 「把文字放大」会撑坏排版，已否决回滚；想要更大只能改 4.0 的排版稿。
