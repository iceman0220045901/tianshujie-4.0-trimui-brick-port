# 09 · 资源路径与大小写

这块 SD 卡是 **FAT32（vfat）**，但它的文件名查找**区分大小写** —— 这是本项目反复踩坑的源头。

---

## 一、实测结论（不要凭 mount 参数猜）

挂载参数：

```
rw,sync,relatime,fmask=0000,dmask=0000,allow_utime=0022,codepage=437,iocharset=utf8,shortname=mixed,errors=continue
```

看着像"不区分大小写"（`shortname=mixed`），但实测：

```sh
$ head -c 20 data/Help/1.txt
head: data/Help/1.txt: No such file or directory      # 大写 H → 找不到

$ head -c 20 data/help/1.txt
（正常输出）                                            # 小写 h → 找得到
```

进一步：

- 磁盘上是 `HZMB.DAT` 时，`fopen("hzmb.dat")` 与 `ls hzmb.dat` 都失败；
- 「只改大小写」的 `mv` 也失败：`mv: can't rename 'HZMB.DAT': File exists`。

**结论**：文件名的解析路径是大小写敏感的；改大小写必须**两步改名**（先改成中间名，再改成目标名）。

---

## 二、实战：内置攻略打不开（本项目最后一个大坑）

详见 [10 · 内置攻略与剧情变色](10-内置攻略与剧情变色.md)。这里只记路径部分：

| 环节 | 内容 |
|---|---|
| 引擎要的路径 | `CONFIG.HelpPath = CONFIG.DataPath .. "Help/"`，`DataPath = "data/"` → **`data/Help/`** |
| 卡上实际 | `data/help/`（小写） |
| 后果 | `existFile()` 全 false → 菜单为空 → 静默返回 |
| 修法 | `mv help hlp_tmp && mkdir Help && cp hlp_tmp/*.txt Help/ && mv hlp_tmp help_orig_lowercase` |

注意：`mkdir data/Help` 在和 `data/help` 并存时会失败（vfat 的创建检查按不区分大小写，报 `can't create directory`）—— 所以必须先 `mv` 走原目录，再建新目录。

## 三、为什么「只看字符串表」会误判

从脚本字节码的字符串表里能搜到 `"Help/"`，很容易得出「相对工作目录的 `Help/`」结论 —— 这是错的。真实路径是**拼接出来的**：

```
GETTABLE "DataPath"  →  LOADK "Help/"  →  CONCAT  →  SETTABLE "HelpPath"
```

所以要在反汇编里找到 `HelpPath` 的赋值上下文，才能确定最终是 `data/Help/`。

> 本项目为此在端口根目录建过一次 `Help/`，重试无效——弯路已写进 [10](10-内置攻略与剧情变色.md)。

---

## 四、通用处理策略

1. **以「引擎/脚本实际请求的精确大小写」为准**准备资源，而不是以磁盘上现有的为准；
2. **大小写不敏感比较**在代码侧兜底：例如音频的 `jy_ci_equal()`（比较前统一小写），失败再试其它扩展名；
3. **批量检查工具化**：把脚本里出现的所有资源路径提取出来，逐条在设备上 `ls`/`head` 验证；
4. **改名永远两步**：`mv a tmp && mv tmp B`，且中间名不能和目标冲突。

## 五、可复用的检查片段

```sh
# 在设备上验证某个资源是否按预期大小写可读
f="data/Help/1.txt"; [ -r "$f" ] && echo OK || echo "MISS: $f"

# 批量验证：从清单逐行读路径
while IFS= read -r p; do [ -r "$p" ] || echo "MISS $p"; done < /tmp/paths.txt
```

```python
# PC 侧：大小写不敏感地在目录里找到真实文件名
def resolve_ci(root, want):
    import os
    for f in os.listdir(root):
        if f.lower() == want.lower():
            return os.path.join(root, f)
    return None
```

## 六、教训

- **mount 参数不能当作行为保证**，必须实测（`head` 一条命令就够，成本极低）；
- 「Windows 打包 + Linux 运行」的组合，**默认所有路径都可能有大小写问题**；
- 报 `No such file` 但 `ls` 看得到同名文件时，先怀疑大小写，不要怀疑权限。
