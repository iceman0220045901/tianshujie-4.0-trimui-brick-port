# 12 · 移植其他版本：复用手册与检查清单

目标读者：想把这套流程用到 **天书劫 3.x** 或 **其他 jysdl-bh（SDL2 分支）游戏** 上的人。

---

## 一、判断能不能复用

| 条件 | 能否复用 |
|---|---|
| 同引擎（jysdl-bh SDL2 分支，`src/` 下有 `jymain.c` `sdlfun.c` `luafun.c` `mainmap.c`） | ✅ 补丁脚本与直写后端可直接用 |
| 引擎是 SDL1.2 分支 | ⚠️ 直写思路可用，但补丁位置不同（参考 4in1 那条线） |
| 完全不同的引擎（Unity/自研/其它） | ❌ 只借用「方法」：抓帧取证、大小写、输入链路 |

---

## 二、开工前先回答六个问题

1. `set.ini` 的 `CONFIG.Width/Height` 是多少？（决定内部渲染面）
2. 有没有 **全屏级底图**（如 `TITLE.png`）按屏宽画死？（决定能不能缩放到别的比例）
3. 主脚本是 **文本 Lua 还是字节码**？路径由 `config.lua` 的 `CONFIG.JYMain_Lua` 指向哪份？
4. 脚本/数据是 **GBK** 吗？
5. 音频走 **BASS + MIDI** 还是 mp3/wav？`CONFIG.MP3` 是多少？
6. 立绘是 `lib.LoadPicture(path,x,y,zoom)` 吗？旧版同作品有没有现成的框尺寸可抄？

---

## 三、操作顺序（照这个顺序，返工最少）

```
1. 只跑通原路径（不设 JY_FBDEV），确认数据完整、能启动
2. 开 JY_FBDEV=1，抓帧确认画面
3. 定 JY_SURF_W/H（= 排版尺寸），定 JY_FB_SCALE（= 面板宽/排版宽，取"不裁边"的最大）
4. 加遮罩（先上下框，别一上来整圈框）
5. 接 gptokeyb，用 jyinject 验证到菜单能动
6. 修音频（入口/大小写/MP3 标志/音量/默认开关）
7. 修立绘（固定框，先抄旧版数值）
8. 资源大小写全量检查（尤其 data 下所有子目录）
9. 功能级验证（菜单一个个点，抓帧留证）
```

---

## 四、检查清单（可逐条打勾）

### 环境
- [ ] target 是 `aarch64-linux-gnu.2.33` 或更低
- [ ] `-rpath` 含 `/usr/trimui/lib:/usr/lib:$ORIGIN`
- [ ] 二进制推到卡上后 `chmod 777`
- [ ] 脚本换行是 LF（不是 CRLF）

### 显示
- [ ] `JY_FBDEV=1` 生效（`fbdev.txt` 有 `fbdev init`）
- [ ] 内部面 = `set.ini` 的 Width/Height
- [ ] `JY_FB_SCALE` 取"不裁边最大等比"
- [ ] 放大/缩小算法：缩小时是盒式，不是最近邻
- [ ] 遮罩镂空与画面矩形严丝合缝（`png_hole.py` 量过）

### 输入
- [ ] `gptokeyb` 与引擎进程并存
- [ ] `/proc/<pid>/fd` 看到 `/dev/uinput`、`/dev/input/event3`
- [ ] `keylog.txt` 有 `sym=`
- [ ] 菜单高亮能动（抓帧对比）

### 音频
- [ ] `music open` → `music play OK ... active=1`
- [ ] `diag: font=1 code=0`（音色库挂上）
- [ ] 音量 ≥ 50/40
- [ ] 默认开关已打开（或明确保持原版行为）

### 资源
- [ ] `data/` 下所有目录名与脚本请求的**精确大小写**一致
- [ ] 连续编号的资源（如攻略 `1.txt..N.txt`）没有断号
- [ ] 扩展名大小写（`.MID` vs `.mid`）已处理

### 稳定性
- [ ] 从 Ports 启动、退出后 MainUI 恢复
- [ ] 连续启动 3 次不残留进程（`pidof jysdllua` 为空）

## 五、各版本的差异点（已知）

| 版本 | 显示 | 脚本 | 备注 |
|---|---|---|---|
| 3.45.1（旧移植） | 直接塞固定框、按 640×480 放大 | 文本 Lua + `hotfix.lua` | 立绘 146/130 的出处 |
| 3.99X | 同上 | 字节码，反编译后中文键乱码 | 需按 GBK 还原键名 |
| 4.0（本项目） | 1280×720 排版 | 字节码，`HelpPath=data/Help/` | 走 fbdev 直写 + 0.8 |

> 3.x 与 4.0 的数据**不能混用**（脚本与素材一一对应）；换版本时把 `data/`、`script/`、`set.ini` 整体替换，不要局部覆盖。

## 六、可以直接拿走的产物

| 文件 | 用途 |
|---|---|
| `patches/patch_fbdev.ps1` | 给引擎加直写后端（幂等） |
| `tools/fbdev_block.c` | 直写 + 盒式缩放 + 遮罩合成，可直接替换进 `sdlfun.c` |
| `tools/jyinject.c` | 无头设备上验证输入链路 |
| `tools/raw2png.py` | 抓帧转 PNG |
| `tools/head_fix.py` | 立绘批量预缩（不需要 PIL） |
| `tools/png_hole.py` | 遮罩镂空包围盒 |
| `release/launch.sh` | 启动脚本模板（含 MainUI 挂起/恢复、gptokeyb、重试） |
| `release/jysdllua.gptk` | 键位映射模板 |
| `release/fix-help-case.sh` | 攻略目录大小写修正 |

## 七、最容易重复犯的五个错

1. 一上来就改内部渲染面，导致文字裁边（先看 `set.ini`）；
2. 用整圈机框配 0.8 缩放，框被裁断（用上下框）；
3. 立绘把 `zoom>100` 一律按 100，把小头像压成拇指图（用固定框）；
4. 只凭字符串表里的一段路径建目录，漏了拼接前缀；
5. 反复重启设备/杀前端进程，把机器搞成无界面状态（优先"运行中改数据目录"，改完重进菜单即生效）。
